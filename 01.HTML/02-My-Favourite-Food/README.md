# My Favourite Food – Hyderabadi Chicken Biryani

This is my second mini project while learning HTML.

I created a simple webpage about one of my favourite foods,
Hyderabadi Chicken Biryani, using only HTML.

## What I Practiced

- Semantic HTML tags
- Adding images
- Lists
- Tables
- Links
- Figure and figcaption

## What I Learned

While building this project, I got more comfortable with
structuring a webpage using semantic HTML elements like
`header`, `main`, `section`, `figure`, and `footer`.

## About This Project

I wanted to keep this project simple and focus on using HTML
to organize and present content without using CSS or JavaScript.
